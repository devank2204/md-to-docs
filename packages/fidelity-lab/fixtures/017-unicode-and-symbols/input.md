# Unicode and Multilingual Typography Fidelity

This fixture verifies Unicode character preservation, CJK scripts, emojis, and typographic entities across Word (.docx) and HTML clipboard export.

## Typographic Quotes and Dashes
“Smart double quotes” and ‘smart single quotes’ — separated by an em—dash and an en–dash.
Ellipses should be preserved properly… not flattened.

## Multilingual Characters & Diacritics
- Japanese (Kanji/Kana): 東京都千代田区霞が関 (Tokyo, Chiyoda-ku, Kasumigaseki)
- Traditional Chinese: 繁體中文國際化測試 (Internationalization test)
- Arabic (RTL text segment): اللغة العربية لغة سامية
- Accented Latin: Français: déjà vu, résumé, naïve façade; Español: niño, año, ¿cómo estás?
- German: Grüßen, Straße, Übergrößen.

## Technical Symbols & Arrows
- Mathematical symbols: ∀x ∈ ℝ, ∃y > 0 such that x² ≥ 0, ±∞, ≈, ≠, ≤, ≥, ∑, ∏, ∫.
- Directional arrows: ← ↑ → ↓ ↔ ⇄ ⇒ ⇔.
