The storyboard is a structural proposal with illustrative content. It simulates
view, theme, review, and preparation states; it does not implement conversions.
Run a static server in this directory to explore it, for example
`python -m http.server 4180 --bind 127.0.0.1` and visit
`http://127.0.0.1:4180/experience-storyboard.html`.

The app's cream palette and existing typography are protected. Dark app appearance
is proposed separately from document styling. The storyboard changed no app files;
the subsequent authorized identity restoration is documented in D002.

Sources: pinned [gstack](https://github.com/garrytan/gstack) and
[Impeccable](https://github.com/pbakaus/impeccable). See the plan's provenance section
for exact revisions and which workflows actually ran.

The earlier independent review applies to its saved proposal snapshot. The later
user correction and shared-home restoration are separate decisions/evidence; do
not interpret the older review score as approval of every subsequent document edit.
