# mdtodocs.com Command Palette

## Purpose

Provide expert acceleration without polluting the primary interface.

Likely invocation:

`⌘K` on macOS  
`Ctrl+K` or equivalent elsewhere

---

# Commands

## Navigation

- Search document
- Go to heading
- Go to page
- Find text

## Destination

- Choose Google Docs
- Choose Word
- Choose PDF

## Export

- Copy formatted document
- Download Word
- Export PDF

## Product surfaces

- Open Document Inspector
- Toggle source
- Toggle preview

## Document settings

- Change page size
- Change orientation
- Change margins
- Typography settings

---

# Rules

The command palette is an accelerator.

Do not remove primary visible controls just because a command palette exists.

Commands should use user-facing terminology.

Do not expose implementation commands unless a genuine developer/debug mode exists.
